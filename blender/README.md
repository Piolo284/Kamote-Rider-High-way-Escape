# Kamote Rider in Blender

`kamote_rider_scene.blend` is a 3D model of the game that you can open in Blender 4.2 or newer. It is built from the game's real lane sizes, world colors and vehicle shapes. One game unit is 5 cm, so each lane is 3.4 m wide.

## Download

- [Download the .blend file](https://github.com/Piolo284/Kamote-Rider-High-way-Escape/raw/main/blender/kamote_rider_scene.blend)
- Or clone the repo and open `blender/kamote_rider_scene.blend`.

## What's inside

| Collection | Contents |
|---|---|
| 1–5 | The five worlds, 150 m each: City Highway (flyover, buildings, billboards), Provincial Road (rice fields, nipa huts, sari-sari stores), Mountain Road (cliff, pines, guardrails), Coastal Highway (sea, bangka boats, palms), Urban Road (towers, crosswalks) |
| 6. Secret Manhole Tunnel | LRT tracks in every lane, pillars, purple lamps, moving LRT trains |
| Player | The Kamote 110 and its rider |
| LTO Checkpoint | Booth and cones at the start. The LTO officer chases the player for the first 10 seconds |
| Traffic | Cars, taxis, jeepneys, buses, trucks, vans and tricycles. Oncoming traffic uses the two left lanes |
| Hazards and Pickups | Cones, potholes, barriers, spinning cash and fuel cans |
| Showcase | Every vehicle type parked side by side for close-up viewing |

## How to view it

- Press **Space** to play the 40-second ride through all six areas.
- The scene opens in the **Chase Camera**, the same behind-the-bike view as the game. To switch cameras, select **Overview Camera** or **Showroom Camera** in the Outliner and press **Ctrl+Numpad 0**.
- Press **Numpad 0** to go back to the active camera. Drag with the middle mouse button to look around freely.
- **F12** renders a still, and **Render > Render Animation** renders the whole ride. Output is portrait 1080×1920, like the phone game.

## Rebuilding

The file is generated by `build_scene.py`. After changing the script, rebuild the file with:

```
blender -b --factory-startup --python blender/build_scene.py
```
